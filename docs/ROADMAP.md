Roadmap del Proyecto - English Pro
🎯 Visión General
Construir una plataforma de aprendizaje de inglés técnico con experiencia de usuario premium, sincronización en la nube y métricas de progreso detalladas.

✅ Fase 1: Cimientos y Core (Completado)
[x] Configuración de entorno con Vite + React + Tailwind CSS.

[x] Sistema de rutas con React Router.

[x] Estructuración de datos para ejercicios (JSON).

[x] Lógica de validación de respuestas y feedback visual.

[x] Persistencia local inicial (localStorage).

✅ Fase 2: Cloud & Intelligence (Completado)
[x] Integración de Firebase Auth para sesiones de usuario.

[x] Migración de datos a Firestore (Sincronización en la nube).

[x] Sistema de rachas (Streaks) dinámicas.

[x] Implementación de seguridad básica (Variables de entorno .env).

🚀 Fase 3: Experiencia Premium y Branding (v2.5.0 - Actual)
[x] Rediseño Dashboard: Estética Glassmorphism y banners dinámicos.

[x] Gamificación: Sistema de 4 niveles con progresión visual seccionada.

[x] Identidad Corporativa: Integración del componente Footer con firma QAUPVE.

[x] Optimización de Carga: Uso de Promise.all para datos de Firebase.

🛠️ Fase 4: Study Center & Contenido (Próximos Pasos)
[ ] Refactorización de la Wiki: Adaptar la interfaz de estudio al nuevo diseño Premium.

[ ] Vocabulario Inteligente: Filtros por categoría y estado de "aprendido" o "por aprender".

[ ] Dashboard de Logros: Sección de medallas desbloqueables por hitos (ej. "7 días seguidos", "Módulo Perfecto").

[ ] Editor de Contenido: Panel para que el administrador (QAUPVE) pueda añadir nuevos ejercicios sin tocar el código.

📈 Fase 5: Expansión y QA (Futuro)
[ ] Audio & Pronunciación: Integración de síntesis de voz (Text-to-Speech) para ejercicios de escucha.

[ ] Analítica Avanzada: Gráficas de progreso semanal usando la librería Recharts.

[ ] Cypress Testing Suite: Cobertura total de pruebas E2E para evitar regresiones en nuevas versiones.
