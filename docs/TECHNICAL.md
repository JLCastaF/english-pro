🏗️ Arquitectura GeneralLa aplicación es una SPA (Single Page Application) construida con React + Vite, siguiendo un patrón de arquitectura por componentes y una capa de servicios en la nube.Stack TecnológicoFrontend: React 18Build Tool: ViteEstilos: Tailwind CSS (Arquitectura Utility-first)Iconografía: Lucide-ReactBackend & Auth: Google Firebase (Firestore + Auth)Testing: Cypress E2E

🔒 Autenticación y SeguridadGestión de Sesión (v2.2.0+)Servicio: Firebase Auth.Flujo: El estado del usuario se monitoriza mediante el hook useEffect y el listener onAuthStateChange.Persistencia: Gestionada automáticamente por Firebase (Local Persistence).Protección de Rutas: Implementada mediante validación de auth.currentUser. Si no hay sesión activa, se redirige al login /.Seguridad de DatosVariables de Entorno: Las credenciales de Firebase se gestionan mediante un archivo .env (no trackeado en Git).Reglas Firestore: (En desarrollo) Configuración de permisos para que los usuarios solo puedan leer/escribir en documentos donde request.auth.uid == resource.data.uid.

📊 Gestión de Datos y EstadoCloud Firestore (Estructura de Datos)La base de datos se organiza en una estructura jerárquica para escalabilidad:users/{userId}: Documento con perfil (nombre, racha máxima, fecha de registro).users/{userId}/progress/{topicId}: Sub-colección donde cada documento representa una lección y su estado (completed: boolean).Rendimiento (v2.3.0+)Carga Paralela: Uso de Promise.all() en el Dashboard para reducir la latencia al consultar simultáneamente los datos del perfil y el progreso de los módulos.
